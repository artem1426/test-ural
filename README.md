# Поиск автозапчастей

Приложение на React, Redux Toolkit и Bootstrap ищет производителей по артикулу, а после выбора бренда показывает искомую деталь и её аналоги. В таблице цена и остаток относятся к указанному складу.

## Запуск

Понадобится Node.js 22.18 или новее.

1. Установите зависимости командой `npm ci`.
2. Выполните `npm run dev` и откройте адрес из терминала. Обычно это [http://127.0.0.1:5173](http://127.0.0.1:5173).
3. Введите артикул `01089` и выберите производителя, например OSSCA.

Для запуска собранного приложения выполните `npm run build`, затем `npm start`. Если порт 5173 занят, сервер выберет свободный. При необходимости конкретный порт задаётся через `PORT`.
